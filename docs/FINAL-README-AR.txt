النسخة النهائية - Reverse Tech

تم تنفيذ:
- إرسال بريد للإدارة عند إنشاء أي طلب PCB أو 3D Printing أو SMT Stencil أو قطع ميكانيكية.
- حفظ رسائل اتصل بنا بكامل بيانات الخدمة والشركة والهاتف داخل Supabase.
- إضافة تبويب "رسائل اتصل بنا" في لوحة الأدمن لعرض الرسائل وتغيير حالتها وحذفها.
- استمرار إرسال اتصل بنا إلى البريد وتجهيز رسالة واتساب.

قبل الرفع:
1) شغّل SUPABASE-CONTACT-MIGRATION.sql في Supabase SQL Editor مرة واحدة.
2) ضع ملف .env الحقيقي بجانب server.js. يمكن تشغيل COPY-ENV-TO-FINAL.ps1 بعد فك الضغط على جهازك.
3) npm install
4) npm start

ملاحظة: ملف .env الحقيقي غير مرفق لأنه يحتوي على كلمات مرور ومفاتيح سرية، والنسخة تحتوي على .env.server-template فقط.
