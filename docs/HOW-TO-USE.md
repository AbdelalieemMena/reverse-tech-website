# How To Use - Operations Guide

This guide walks you through running, browsing, and managing the Reverse Tech web application.

---

## 🚀 Running the Local Server

1. Open a terminal or shell in the project folder (`d:\reverse tech\01- website`).
2. Run `npm install` (only needed if dependencies aren't installed).
3. Start the server using:
   ```bash
   npm start
   ```
4. The server will start on port `3000`. You will see this output:
   ```
   ==========================================
     Reverse Tech server شغال على المنفذ 3000
     الموقع:  http://localhost:3000
     الأدمن:  http://localhost:3000/admin.html
   ==========================================
   ```

---

## 🌐 Browsing the Public Website

Open your browser and navigate to:
👉 **[http://localhost:3000](http://localhost:3000)**

- **Language Toggle:** Click the **English/العربية** globe button in the top navigation bar to toggle layout directions instantly.
- **Service Inquiries:** Click **اطلب خدمة** (Request Service) to scroll smoothly to the contact form.
- **PCB Fabrication Calculator:** Scroll down to **أرسل طلب تصنيع لوحات إلكترونية مطبوعة (PCB)** to calculate a cost estimate dynamically.

## 📋 Dashboard Operations Guide

### 1. Managing Projects (المشاريع)
- **Add/Edit Projects**: Fill in the Arabic and English fields. Choose a file to upload or paste a URL. Saved projects immediately sync using SWR caching on the user's browser.
- **Delete Projects**: Click the red **حذف** button to delete instantly.

### 2. Updating Service Pricing (إعدادات الأسعار)
- Under the **إعدادات الأسعار** (Pricing Settings) tab, you can manage parameters for:
  - **أسعار PCB**: Rates per cm² per layer count, Surcharges (color/thickness), Setup Fee, and promo discount codes.
  - **3D Printing**: Base setup fees, unit price per material type, finishing multipliers, thickness multipliers, and quantity discount tiers.
  - **SMT Stencil**: Base price, price per cm², thickness multipliers, and quantity discount tiers. These thickness options dynamically update client select options on [stencil.html](file:///d:/reverse tech/01- website/public/stencil.html) in real time.
  - **القطع الميكانيكية**: Setup fee, minimum order, rush surcharge percent, and quantity discount tiers.
- Click the blue save button at the bottom of the relevant form to save edits.

### 3. Reviewing Client Orders & Messages (الطلبات والرسائل)
- Select the tab for the order type you wish to review:
  - **طلبات PCB**
  - **طلبات 3D Printing**
  - **طلبات القطع الميكانيكية**
  - **طلبات SMT Stencil**
  - **رسائل اتصل بنا**
- Change order/message status via the dropdown (**جديد** / **قيد المراجعة** / **تم التنفيذ** / **تم التواصل** / **منتهي** / **ملغي**) and click **حفظ الحالة** to save. Click **حذف** to permanently delete an entry.
- For PCB and Stencil orders, download the uploaded design files (`.zip` / `.rar`) securely using the temporary link generated by the server.

### 4. Service Slider Media Management (وسائط الخدمات)
- Go to the **وسائط الخدمات** tab.
- Select a service (PCB, SMT Stencil, CNC, 3D Printing, Reverse Engineering).
- You can add new slides (either upload images/MP4 videos directly or paste URLs) and set their media type.
- Click **حفظ وسائط الخدمة** to apply. The slider on the public service page will update instantly without any duplicates or deleted images.
