تحديث إدارة الأسعار:
- تبويب جديد داخل لوحة الأدمن باسم "إعدادات الأسعار".
- تعديل أسعار PCB كاملة: الطبقات، رسوم التجهيز، الحد الأدنى، السُمك، الألوان، العاجل، خصومات الكميات، وكود الخصم.
- تعديل أسعار 3D Printing حسب الخامة والتشطيب والكمية.
- تعديل أسعار SMT Stencil حسب السعر الأساسي، المساحة، السُمك، والكمية.
- إعدادات عامة للقطع الميكانيكية، مع بقاء سعر كل قطعة قابلًا للتعديل من تبويب القطع.
- العميل يستطيع حساب السعر النهائي قبل إرسال طلب 3D أو Stencil أو Mechanical.

الخطوات:
1) شغّل SUPABASE-PRICING-MIGRATION.sql في Supabase SQL Editor.
2) ضع .env بجانب server.js.
3) npm install
4) npm start
5) الأدمن: http://localhost:3000/admin.html
